# `.text` Section — Complete Summary

### Definition

The **`.text` section** contains the **executable machine instructions (program code)** generated by the compiler.

---

### What is stored in `.text`?

* `main()` function
* User-defined functions
* Interrupt Service Routines (ISRs)
* Library function call instructions

Example:

```c
#include <stdio.h>

void fun()
{
    printf("Hello\n");
}

int main()
{
    fun();
    return 0;
}
```

The machine code for `main()` and `fun()` is stored in **`.text`**.

---

### Where is `.text` stored?

* Stored in **Flash/ROM**
* Usually **not copied to RAM**
* The CPU executes instructions directly from Flash/ROM

```text
FLASH/ROM
---------
.text
```

---

### Characteristics of `.text`

* Contains **program instructions**
* **Read-only**
* Exists throughout program execution
* Does not change during runtime
* Occupies Flash/ROM memory

---

### What happens at startup?

```text
Power ON
   ↓
CPU Reset
   ↓
Copy .data (Flash → RAM)
   ↓
Clear .bss (set to zero)
   ↓
Execute code from .text
   ↓
main()
```

Notice:

* `.data` is copied.
* `.bss` is cleared.
* `.text` remains in Flash and is executed directly.

---

### Example Memory Layout

```text
FLASH/ROM                     RAM
---------------------------------------------
.text   -> program code
.data   -> initial values ----> .data
.bss    -> not stored --------> .bss (zeros)
```

---

### Why keep `.text` in ROM?

Because program instructions:

* Must remain permanent
* Do not change during execution
* Would waste RAM if copied

---

### Comparison

| Section | Stores                             | Stored in ROM | Stored in RAM |
| ------- | ---------------------------------- | ------------- | ------------- |
| `.text` | Program code                       | Yes           | No            |
| `.data` | Initialized globals/statics        | Yes           | Yes           |
| `.bss`  | Uninitialized/zero globals/statics | No            | Yes           |

---

## One-line rule to remember:

> **`.text` = Executable program code stored permanently in Flash/ROM and executed by the CPU.**
